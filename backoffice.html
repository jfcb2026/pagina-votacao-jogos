Sincronização entre Membros (nuvem)

Todas as alterações feitas no site (votos, jogos, eventos, etc.) já são enviadas automaticamente para a nuvem, não precisas de carregar neste botão no dia a dia. Só é preciso usá-lo em dois casos: (1) uma única vez, se este browser já tinha dados próprios guardados antes de a sincronização ficar ativa, para os enviar para a nuvem; ou (2) se achares que a sincronização falhou e queres forçar o reenvio dos dados atuais deste browser para a nuvem.

Exportar dados

Descarrega o estado atual de cada lista como ficheiro JSON, para colocar em assets/data/ e enviar (commit) para o repositório.

Cópia de Segurança (Backup)

Guarda todos os dados do site (membros, jogos, votação, passeios, histórico, password, etc.) num único ficheiro. Usa "Importar Backup" para repor esses dados, caso alguma vez seja preciso.
